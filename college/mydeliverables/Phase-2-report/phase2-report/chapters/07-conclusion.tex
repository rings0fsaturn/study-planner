\section{Conclusion}
Phase~I built an open-loop adaptive planner for a single self-directed learner. It estimated pace with Bayesian calibration and enriched shrinkage, and it flagged shifts with CUSUM. It projected completion with a Gaussian process and a cold-start composite, and it regenerated the plan with capacity bookings. Evaluation reported honest nulls with the wins, and the conformal correction and the single-arm CUSUM posture stayed validated but unshipped.

Phase~II closed the loop with assessment-based verification of genuine learning. The principal novelty is the verified-learning closed loop, which extends the predict-then-optimize architecture~\cite{islam2024} from logged time to graded evidence. Logged time stays gameable~\cite{gaming2026}, so the plan responds to graded evidence.

\section{Future Work}
Table rows in Appendix~\ref{ch:appendix} remain the reproducibility base for the work below. Four lines of work follow.

The first is to ship the validated refinements, in particular the split-conformal correction of the projection interval. The single-arm CUSUM posture ships with it, since detection feeds a human-confirmed prompt.

The second is longitudinal validation on real data, comparing closed-loop planning against the static baseline on adherence and on measured learning gain. A single learner over one term gives the honest next step beyond synthetic histories.

The third is difficulty calibration with two or more bands, so the adaptive chip moves from advisory to measured. It needs more eligible questions than the single band available here.

The fourth is classroom scope, extending the single-learner loop to groups without losing per-learner mastery.
