SyncProvider withholds children for a few seconds on a brand-new device's very first sign-in, while it downloads and replays a cloud snapshot into local IndexedDB (D-07/D-08, already agreed and spec’d). Today it shows a bare ProtectedRoute-style “Loading…” card — Rohit picked Option C: a branded moment over that plain reuse. These three panels are concrete candidates for what that moment looks like, each a real, self-contained render (inline SVG built from the actual favicon.svg mark, the same wordmark treatment as SignIn’s .auth-mark, real design tokens). None of this CSS ships yet — it is a proposal for packages/design-tokens/src/components.css.

The safety-timeout duration (currently an undiscussed 8000ms placeholder) is the other open half of D-09. Toggle this to see how each option reads if the restore is still running a few seconds in — useful context for picking that number.

Option C1 — Notebook mark (recommended)
★ Recommended — the favicon mark writes itself in, then names itself

Full-bleed on the paper surface (no card box — there is nothing to frame, so it reads as a moment rather than a dialog). The three ruled lines draw in left-to-right like the mark is being written, the terracotta dot settles in and then pulses quietly — the same pulse vocabulary as the sync indicator and session dot. Wordmark and a plain-language caption cascade in underneath. Warmest, calmest option; closest in spirit to the “quiet companion” auth tagline.
