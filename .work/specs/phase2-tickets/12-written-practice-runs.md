## What to build

Deliver resumable configurable written Practice runs using the shared Question, attempt, grading, mastery, and local-first boundaries.

## Acceptance criteria

- [ ] Learners can configure, start, pause, resume, and complete multi-question written runs.
- [ ] Written Practice uses the same server-authoritative grading and fresh-attempt semantics as Assessments.
- [ ] Valid grades update mastery while paused, abandoned, timed-out, and unsubmitted work creates no observation.
- [ ] The flow works at mobile and desktop widths and survives refresh and reconnect.
